Задача А. Написать программу, выводящую на экран заданную
геометрическую фигуру, нарисованную с помощью заданного с клавиатуры
символа, условие заполнения фигуры и задаваемые параметры фигуры в
таблице (остальные можно взять константные)
Четырехугольник контур r
# 1. Алгоритм и блок-схема
- Начало.
- Настройка окружения: Установка кодировки консоли UTF-8 для корректного вывода русских букв.
- Ввод данных:
	- Запрос и чтение графического символа c.
	- Запрос и чтение радиуса вписанной окружности r.
- Расчет параметров: Вычисление диаметра фигуры d = 2 * r. Он же является размером стороны внешнего четырехугольника.
- Инициализация внешнего цикла (по строкам): Переменная i пробегает значения от 0 до d включительно.
- Инициализация внутреннего цикла (по столбцам): Переменная j пробегает значения от 0 до d включительно.
- Проверка условий для текущей точки (i, j):
	- Условие 1 (Граница рамки): Если i == 0 ИЛИ i == d ИЛИ j == 0 ИЛИ j == d, то:
	- Печать заданного символа c (формируется контур четырехугольника).
	  - Переход к шагу 8.
	- Условие 2 (Контур окружности): Если точка лежит внутри рамки, то:
	  - Расчет декартовых координат относительно центра: x = (j - r) * 1.8, y = (i - r).
		- Вычисление квадрата расстояния до центра: dist = x*x + y*y.
		- Если значение dist находится в диапазоне линии окружности (r*r - r <= dist <= r*r + r), то:
		  - Печать заданного символа c.
		- Иначе (пустое пространство):
		  - Печать пробела " ".
- Переход к следующему столбцу: Увеличение j на 1. Если j <= d, возврат к шагу 7.
- Переход на новую строку: Вывод символа переноса строки \n после завершения обработки всех столбцов текущей строки.
- Переход к следующей строке: Увеличение i на 1. Если i <= d, возврат к шагу 6.
- Конец.
